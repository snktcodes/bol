Not a chatbot. A doer.

A menu-bar app that puts Claude Code behind your voice. It opens apps, runs commands and reads your screen to get things done.

  • Talk with ⌘J One shortcut, anywhere. No wake word; the mic opens only while you talk.
  • Real work on your Mac Every Claude Code tool: shell, files, web, MCP servers, Claude in Chrome.
  • Frontier models only Claude Opus 5.5 or Fable 5.2, never below medium effort. No smaller models.
  • Computer use, built from scratch Its own computer use, without the guardrails: it sees your screen and clicks, types and scrolls in any app. No per-app prompts.
  • Background tasks Long jobs run on their own. Bol comes back when they're done.
  • Dictation everywhere Hold fn in any text field, speak, let go. The text lands where you're typing.
  • Threads and memory Every conversation and step, searchable. Memory in plain markdown you own.
  • Interrupt any time Esc silences it. ⌘J cuts in. Say “stay with me” to watch it work.
  • Voices Free macOS voices, or OpenAI and Noiz AI with your own key.
  • Doesn't stop to ask Full permissions on your Mac: it acts instead of asking for approval. Be specific.

How it works

Voice in, finished work out. The thinking runs in Claude Code on your Mac, on your Claude account.

  1. ⌘JMic opens, echo-cancelled
  2. hearLive speech-to-text on your subscription
  3. thinkOpus 5.5 or Fable 5.2, medium effort or more
  4. actShell, files, apps, browser, screen; long jobs run as tasks
  5. speakA spoken reply, then it listens for a follow-up

No API key, no new bill

Bol uses your Claude Code and its subscription, speech-to-text included. Cloud voices are optional.

Your Mac, your files

Threads, tasks, memory and dictations live in ~/.bol as plain files. Bol keeps its own transcripts, so Claude Code's cleanup never takes your history.

You decide how much it can do

Every macOS permission is optional and screen access is a switch. What you grant, Bol uses without asking.

FAQ

What do I need to use Bol?

macOS 13+, Claude Code, and a Claude Pro or Max subscription. Setup checks all three.

Do I need an Anthropic API key?

No. Bol runs on your Claude subscription through Claude Code.

Is Bol open source?

Yes, MIT-licensed. The app, its brain and this site are on GitHub.

Which AI models does Bol use?

Claude Opus 5.5 (default) or Fable 5.2, never below medium effort. Raise it in Settings → Assistant.

Is the microphone always on?

No. It opens when you press ⌘J or hold the dictation key, and closes when you're done. No wake word.

What can it actually do?

Anything Claude Code can do on your Mac, plus its own computer use: it sees your screen and clicks and types in any app.

Will it do something destructive without asking?

It can. Permission checks are off, so it won't pause before running sudo or sending a message. It's instructed to move anything it deletes to the Trash rather than erase it, so a mistake can usually be put back. Be specific.

Where is my data stored?

On your Mac, in ~/.bol. Requests go to Anthropic through your Claude account; a cloud voice gets the reply text.

Does it replace my dictation app?

It can, or keep yours: give Bol another key or turn its dictation off. Setup suggests this when it finds one.
